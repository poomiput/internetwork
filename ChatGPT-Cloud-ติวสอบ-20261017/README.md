# ชุดส่งต่อการติว Internetworking ไปยังแชตบนคลาวด์

ชุดนี้เป็นสำเนาเอกสารและบริบทการเรียนพร้อมส่งต่อ เรียงตามหัวข้อสอบ 120 ข้อ เป็นโฟลเดอร์ปกติ ไม่ได้สร้าง ZIP

## เริ่มใช้งาน

1. เริ่มจากส่ง `00_เริ่มที่นี่_วิธีสอน.md` และ `02_สถานะเรียนและคำถามค้าง.md` ให้แชตใหม่อ่าน พร้อมบอกว่าให้ใช้เป็นบริบทและคำแนะนำการติว
2. ส่ง `01_ขอบเขตสอบและสารบัญ.md` เพื่อให้เห็นลำดับบทและน้ำหนักข้อสอบ
3. ส่ง PDF ของบทที่กำลังเรียน พร้อม Markdown ถ้ามี รอบแรกใช้โฟลเดอร์ `01 - QoS` รูป/ตาราง/ไดอะแกรมให้ดูใน PDF ตามเลขหน้า
4. เมื่อเปลี่ยนบท ให้ใช้เอกสารจากโฟลเดอร์บทนั้นและอัปเดตสถานะการเรียน ไม่จำเป็นต้องให้ผู้สอนอ่าน PDF ทุกบทใหม่ในทุกข้อความ

โฟลเดอร์แต่ละบทมี PDF ต้นฉบับคงชื่อเดิม สามารถเลือกไฟล์ที่จะส่งได้ตรงบท ชุดนี้ไม่มีลิงก์ที่ต้องอาศัยไฟล์บนเครื่องเดิม

ข้อความพร้อมคัดลอกเพื่อเริ่มแชต: [ข้อความเริ่มแชต.txt](ข้อความเริ่มแชต.txt)

## สิ่งที่รวมมา

- PDF 12 ไฟล์ รวม 755 หน้า รวมบท Wireless Troubleshooting ที่ผู้เรียนส่งเพิ่ม
- Markdown ช่วยอ่าน 7 ไฟล์จากงานแปลงที่มีอยู่เดิม ปรับการอ้างรูปให้เป็นเลขหน้าใน PDF
- โฟลเดอร์หัวข้อสอบครบ 9 กลุ่ม กลุ่ม 8 ยังไม่มี Lec แยก ส่วนกลุ่ม 9 มีบท Wireless และ README ระบุส่วนของขอบเขตสอบที่ยังไม่ยืนยัน
- วิธีสอนแบบแบ่งช่วง 2–8 ช่วง/บท คำถามช้อยส์ Active Recall การรอคำตอบและเฉลย การทบทวนจุดพลาด และข้อกำหนดไม่ทำโน้ต A4 ตอนนี้
- สถานะ QoS ช่วง 1/6 คำถามแทรกเรื่อง Best Effort และแบบฝึกหัดที่ยังรอคำตอบ
